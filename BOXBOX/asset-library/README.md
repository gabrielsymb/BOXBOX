# Biblioteca de assets do BOXBOX

Esta biblioteca recomeçou vazia em 19 de novembro de 2026 após a remoção dos
assets usados apenas em testes visuais.

## Estados

- `review`: candidatos baixados para inspeção, fora do projeto Godot;
- `active`: assets aprovados, copiados seletivamente para `BOXBOX/boxbox/Assets/`;
- `rejected`: registro opcional de candidatos recusados quando a justificativa
  ajudar decisões futuras.

Nenhum arquivo entra em `active` sem fonte, autor, licença, data de obtenção e
resultado da inspeção técnica. A seleção artística depende de aprovação visual do
usuário.
