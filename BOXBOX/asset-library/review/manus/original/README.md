# Arquivo original do protagonista

Pacote fornecido pelo criador do BOXBOX via [Manus](https://manus.im/share/file/33c72025-bcdc-478e-8dcf-179abdbeeed8). As partes são fatias do ZIP original. Para reconstruir no Linux ou macOS, execute nesta pasta:

```sh
cat character_gameplay_blender_godot.zip.part-01 character_gameplay_blender_godot.zip.part-02 > character_gameplay_blender_godot.zip
shasum -a 256 -c SHA256SUMS
```

O jogo já inclui o GLB otimizado em `BOXBOX/boxbox/Assets/Characters/NewCast/boxbox-player-fiel.glb`. O ZIP preserva os modelos originais, o rig, os clipes e o prop fornecido.
