# Grocery interface art

Kenney, CC0 1.0. The gameplay interface uses selected PNGs from [Food Kit](https://kenney.nl/assets/food-kit), [Mini Shop](https://kenney.nl/assets/mini-shop) and [Game Icons](https://kenney.nl/assets/game-icons). Originals and pack licenses are in the repository asset library.

The interior scenes use selected Mini Shop GLBs and their original shared colormap.

The cash HUD frame is `Grey/Default/button_rectangle_border.png` from [Kenney UI Pack 2.0](https://kenney.nl/assets/ui-pack), CC0 1.0, tinted in Godot. Its icon uses the Mini Shop cash register preview.

The personal wallet uses the Kenney Game Icons single-player icon. The coffee action uses the Kenney Food Kit mug preview. The shop interiors reuse Mini Shop meshes.

The grocery walls use [Blue Plaster Weathered](https://polyhaven.com/a/blue_plaster_weathered). The wholesaler walls use [Concrete Brick Wall 001](https://polyhaven.com/a/concrete_brick_wall_001). Both are Poly Haven CC0 materials applied as direct diffuse, normal and roughness maps. Floors use the original Mini Shop materials.

The minimap pointer is the existing Kenney Game Icons `arrowUp.png` asset. Mission targets reuse the same pack's `target.png`. The subtitle backing uses the same nine-slice UI Pack frame as the cash HUD.
